# ✅ **PART 1 — Laravel Backend Scaffold (attendance-backend)**

## 1. Create Laravel project

```bash
composer create-project laravel/laravel attendance-backend
cd attendance-backend
```

---

## 2. Install Sanctum (API authentication)

```bash
composer require laravel/sanctum
php artisan vendor:publish --provider="Laravel\Sanctum\SanctumServiceProvider"
php artisan migrate
```

---

## 3. Create Models + Migrations + Resource Controllers

### ⭐ Student

```bash
php artisan make:model Student -mcr
```

This generates:

* Model: `Student.php`
* Migration
* Controller: `StudentController.php`
* Resource: `StudentResource.php`

---

### ⭐ Attendance

```bash
php artisan make:model Attendance -m
php artisan make:controller AttendanceController
php artisan make:resource AttendanceResource
```

---

## 4. Create Form Request validation classes

```bash
php artisan make:request StoreStudentRequest
php artisan make:request UpdateStudentRequest
php artisan make:request BulkAttendanceRequest
```

---

## 5. Create Service Layer for attendance logic

```bash
mkdir app/Services
touch app/Services/AttendanceService.php
```

---

## 6. Create Event & Listener

```bash
php artisan make:event AttendanceRecorded
php artisan make:listener SendAttendanceNotification --event=AttendanceRecorded
```

---

## 7. Create Artisan command

```bash
php artisan make:command AttendanceGenerateReport
```

---

## 8. Create Tests

```bash
php artisan make:test StudentTest
php artisan make:test AttendanceTest
php artisan make:test ReportTest
```

---

## 9. Run migrations

```bash
php artisan migrate
```

---

# 🔥 Your Laravel backend scaffold is now ready.

---

# ✅ **PART 2 — Vue 3 SPA Frontend Scaffold (attendance-frontend)**

Go outside the Laravel folder:

```bash
cd ..
```

---

## 1. Create Vue 3 project with Vite

```bash
npm create vite@latest attendance-frontend -- --template vue
cd attendance-frontend
npm install
```

---

## 2. Install Vue Router, Pinia, Axios, Chart.js

```bash
npm install vue-router pinia axios chart.js vue-chartjs
```

---

## 3. Create folder structure

```bash
mkdir src/pages
mkdir src/components
touch src/router.js
```

---

## 4. Run frontend

```bash
npm run dev
```

Access at:

* Vue SPA → [http://localhost:5173](http://localhost:5173)
* Laravel API → [http://localhost:8000](http://localhost:8000)

---

# 🎯 BONUS — API connection in Vue

Install CORS for backend:

```bash
composer require fruitcake/laravel-cors
```

Enable API URL in `.env`:

```
APP_URL=http://localhost:8000
FRONTEND_URL=http://localhost:5173
```
